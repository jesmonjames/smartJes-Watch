WAVE // smartJO Watch visual prototype

Windows 11 quick start:
1. Download and extract prototype.zip.
2. Open index.html in Microsoft Edge or Google Chrome.
3. Use the sliders to test glow, ring speed, and accent intensity.
4. Switch looks with Blue-Green Mix Mode or the red Stress Mode.
5. Click Full-screen preview if desired.

Prototype notes:
- The watch screen in the page is authored at 240 x 296 CSS pixels.
- This is a browser UI mockup, NOT a flashable firmware file or a verified boAt watch-face package.
- Battery level is read from your PC when the browser supports the Battery Status API (Edge/Chrome); steps and BPM are simulated.
- Full-screen preview isolates the watch chassis; press Esc or the button again to exit.
- On phones, the compass and tilt read device-orientation sensors. iOS Safari may ask for motion permission.
- Please confirm the exact model and resolution from its product/manual/app before attempting any device-specific export.
